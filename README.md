# 🌤️ Dynamic Full-Screen Weather Dashboard

A sleek, modern, and fully responsive weather dashboard built with vanilla HTML, CSS, and JavaScript. This application fetches real-time weather conditions for any city globally and displays a historical 5-day weather forecast.

## ✨ Features

* **Real-Time Data:** Displays current temperature, "feels like" temperature, humidity, wind speed, and visibility.
* **Historical Data:** Shows the high/low temperatures and weather conditions for the past 5 days.
* **Smart Error Handling:** Provides clear UI feedback for typos, invalid city searches, or pending API key activations.
* **No Build Tools Required:** Pure vanilla web technologies—just open and run.

## 🛠️ Technologies Used

* **HTML5 & CSS3:** For structure and styling.
* **Vanilla JavaScript:** For fetching data and updating the DOM dynamically.
* **[OpenWeatherMap API](https://openweathermap.org/):** Used for real-time weather data and geocoding.
* **[Open-Meteo API](https://open-meteo.com/):** Used to fetch free historical weather data (past 5 days) using coordinates.
* **[FontAwesome](https://fontawesome.com/):** For UI icons.
